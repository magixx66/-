# 启生 CreatorOS

面向个人自媒体创作者的本地工作台。React 19 + TypeScript + Vite。

## 运行

```sh
npm ci --cache /tmp/creator-npm-cache
npm run dev
```

构建：`npm run build`。默认开发端口为 5173。

## 当前能力

- 今日工作台：项目进度、待办、排期。
- 选题与脚本：创建、编辑、删除，Markdown 导出。
- 内容流水线：拖拽卡片或下拉切换阶段。
- 素材库：本地图片、音频、视频上传与预览（单文件 1.5 MB 以内）。
- 发布日历：排期记录，点击日期查看安排；不自动发布。
- 数据复盘：手动录入已发布作品播放和点赞，汇总及对比。
- 创作者档案、本地规则助手，建议新增选题需明确确认。
- 浏览器 localStorage 自动保存，JSON 备份导出与恢复。

初始内容及数据为示例。AI 助手没有连接在线模型，平台 API、自动发布、云同步尚未接入。数据仅保存在当前浏览器中，建议定期导出备份。大文件需要未来接入本地文件系统或对象存储。

## 验证

`npm run build` 执行 TypeScript 检查和生产构建。

端到端验证：`npm test`。检测到系统 Chromium 时自动使用；否则先执行 `npx playwright install chromium` 安装浏览器。测试覆盖持久化、导航与筛选、项目阶段、建议确认、素材管理、排期与指标、备份、移动端。

## 本次优化

- **关联待办**：支持新增、编辑、完成与删除，关联作品、截止日期和优先级；完成项可隐藏。
- **结构化创作包**：Hook、口播正文、CTA、分镜/B-roll、参考资料和发布文案；口播预览、字数/时长估算、完整 Markdown 导出。
- **编辑草稿恢复**：未提交内容自动保留，关闭或刷新后可以继续；`Ctrl/Cmd + S` 保存到项目。可明确丢弃草稿，不影响已保存内容。
- **发布准备**：标题/稿件自动检查，事实、封面、字幕与文案手动检查；进度只代表记录的完成情况。
- **真实排期**：日历从当前日期开始，可回到今天、设置时间、按时间查看当天安排；同平台同时间冲突会提醒。
- **创作简报**：创作者档案加入内容边界与可复用经验；当前稿件、平台和档案共同进入可复制/导出的 AI 简报。助手可保留当前作品上下文。
- **兼容与恢复**：旧数据自动补充字段，旧布尔待办保留完成状态；备份升级为 v2（含草稿与待办），兼容 v1，导入前完整校验。存储失败会显示提示。
